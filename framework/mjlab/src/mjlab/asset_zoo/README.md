# Asset Zoo

This local mjlab subset contains the Unitree Go1 MJCF, meshes and model constants
in [robots/unitree_go1](robots/unitree_go1). Go1 task configurations live in
[go1_tasks](../../../../../src/go1_tasks/README.md); Go2 uses its own MJCF in
[go2_tasks](../../../../../src/go2_tasks/README.md).

Model or joint-order changes should be checked against both the task tests and
the independent [sim2sim](../../../../../sim2sim/README.md) deployment models.
