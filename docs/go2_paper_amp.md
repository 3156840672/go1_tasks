# Go2 论文式 Rough AMP 与 LSTM 学生

> 当前状态：训练已停止，判别器单侧门限已移除，地形课程已修正。
> 第6–9节记录历史实验，第10节说明当前有效配置；旧实验命令课程不再生效。

本实现对应 Wu 等人的 *Learning Robust and Agile Legged Locomotion Using
Adversarial Motion Priors*（RA-L 2023）两阶段方法。参考动作继续读取
`logs/amp/go2_paper_reference` 中由现有 OCS2 轨迹构建的论文式数据。
参考动作只参与教师阶段的 AMP 判别器训练；学生阶段通过教师动作继承风格。

## 1. 网络结构

教师输入分为三组：

| 输入 | 维度 | 用途 |
| --- | ---: | --- |
| 本体观测 | 45 | 角速度3、投影重力3、关节角12、关节速度12、上一动作12、命令3 |
| 特权状态 | 30 | 仿真速度、足端接触力/状态、摩擦、质量/质心、电机强度和碰撞状态 |
| 地形扫描 | 187 | 机身周围的局部高度采样，只在教师训练中使用 |

网络与论文 Table III 一致：

```text
30  -> 64 -> 32 -> 8       privileged encoder
187 -> 256 -> 128 -> 16    terrain encoder
45 + 8 + 16 = 69
69  -> 256 -> 128 -> 64 -> tanh(12)  low-level policy
```

Critic 使用现有 259 维非对称观测。AMP 判别器严格使用论文定义的 31 维单帧
状态：机身相对地形高度 1、机身线速度 3、机身角速度 3、关节角 12、关节速度
12。输入为相邻两帧，因此网络结构是 `62 -> 1024 -> 512 -> 1`，两个隐藏层均
使用 ELU，输出层为线性单元。参考 NPZ 中的投影重力和足端位置仍可用于数据
校验和状态重置，但不会送入论文判别器。

判别器结构保持论文值不变。优化器对两个隐藏层使用 `1e-3` 权重衰减，对最终
分类头使用 `1e-1` 权重衰减。这与完整 AMP 参考实现的分组正则化一致，用于避免
小型参考集被最终分类头迅速记住。训练时应同时观察 `amp_expert_logit`、
`amp_policy_logit` 和 `amp_style_reward_raw`；若前两者长期固定在 `+1/-1` 且
风格奖励接近零，说明判别器仍然饱和，不能据此开始学生蒸馏。

论文报告的整个参考集为30秒，并且只包含Trot风格。本项目为改善零指令踏步，
在30秒方向Trot之外加入1.6秒真实稳定站立数据；这是工程扩展，不是论文原始分布。
使用以下命令从原始17段
多步态数据中选出前进、后退、左右横移和左右转向的12段Trot轨迹，再截取每段
稳定的中间2.5秒，并从原有站立片段中截取中间1.6秒：

```bash
.venv/bin/python tools/build_go2_paper_amp_dataset.py
.venv/bin/python tools/validate_go2_amp_dataset.py \
  logs/amp/go2_paper_reference --allow-partial --expected-seconds 2.5 --stand-seconds 1.6
```

结果为13段、1580个相邻帧转移、总计31.6秒。站立占`5.06%`，六个方向类别各占
`15.82%`。读取器按相邻帧转移均匀抽样，站立占比由时长决定，不是按文件数计算。
在已有输出上重建可加`--overwrite`；用干净输出目录和`--stand-seconds 0`可重建
原始30秒Trot-only集合，但不能同时沿用当前包含零命令风格学习的配置。
原目录`logs/amp/go2_reference`保持不变，继续供普通多步态AMP使用。

论文只列出 30 维特权状态的类别，没有公开每项在 30 维向量中的精确索引。
本项目按 Go2 仿真中真实存在并参与随机化的量定义固定的 30 维布局，没有填入
永远为零的外力占位量。这个差异不改变 30→8 的学习方式，但做逐元素复现实验时
应在原作者代码可用后再次对齐。

学生只接收当前 45 维本体观测：

```text
45 + h(t-1) + c(t-1) -> LSTM hidden 256
256 -> 256 -> 128 -> 24             memory encoder
45 + 24 -> 256 -> 128 -> 64 -> tanh(12)
```

学生的低层网络先复制教师权重，然后继续训练。训练序列默认 50 帧，也就是
50 Hz 控制下的 1 秒历史。LSTM 不需要把 50×45 个观测显式放进部署输入。

## 2. 第一阶段：训练 AMP 教师

```bash
uv run go2-train Go2-Velocity-Rough-AMP-Teacher \
  --env.scene.num-envs 1024 \
  --agent.logger tensorboard \
  --agent.upload-model False
```

输出目录为 `logs/rsl_rl/go2_paper_amp_teacher/<run>/`。启动日志应显示 45 维
actor、30 维 privileged、187 维 terrain、259 维 critic，以及：

```text
[AMP] 13 clips, 1580 transitions, 50 Hz
```

教师阶段同步训练 PPO actor/critic 和 AMP 判别器。参考集已包含稳定站立，
`zero_command_amp_threshold=0.0`表示关闭零指令屏蔽，严格零速度样本正常参与
AMP风格奖励与策略回放。命令采样仍保留5%严格零指令。速度课程按参考数据的实测速
度启动，而不是按文件名中的手柄输入值启动：前后 `±0.3 m/s`、横向
`±0.2 m/s`、偏航 `±0.55 rad/s`；第 3500 轮扩为 `±0.6、±0.4、±0.75`，
第 6000 轮达到正常部署范围 `±1.0、±0.6、±1.0`。因此最终能力范围没有缩小，
同时避免判别器在早期只靠速度识别真假。5% 严格零命令、地形课程、域随机化、
4-8 秒随机扰动以及参考状态重置保持启用。
论文式教师的地形课程按线速度跟踪质量升降：命令平移速度大于 `0.1 m/s`、
episode 至少达到最大时长的 50%，且归一化跟踪奖励达到 85% 才升级；早摔或
跟踪奖励低于 50% 时降级。零速度和纯转向 episode 不参与地形升降。
正式蒸馏前应先评估多个教师 checkpoint，确认速度跟踪、转向和步态已经收敛。

旧 checkpoint 使用了不同的参考集、92维输入或`256, 128`判别器结构，恢复时应保留
actor/critic和PPO优化器，但重新初始化判别器：

```bash
uv run go2-train Go2-Velocity-Rough-AMP-Teacher \
  --env.scene.num-envs 1024 \
  --agent.resume True \
  --agent.load-run <旧运行目录> \
  --agent.load-checkpoint model_<轮数>.pt \
  --agent.algorithm.reset-discriminator-on-resume True \
  --agent.max-iterations <追加轮数> \
  --agent.logger tensorboard \
  --agent.upload-model False
```

该开关只应用于这次恢复。后续从修复后的 checkpoint 正常续训时不要再传它，
否则会再次清空已经重新学习的判别器。

## 3. 第二阶段：DAgger 蒸馏 LSTM 学生

```bash
uv run go2-train-paper-amp-student \
  --teacher logs/rsl_rl/go2_paper_amp_teacher/<run>/model_9999.pt \
  --num-envs 256 \
  --iterations 4000 \
  --sequence-length 50 \
  --epochs 4 \
  --batch-size 32
```

每轮由学生控制仿真，因此采到的是学生真正会访问的状态；冻结教师在这些状态上
产生 12 维目标动作和 24 维目标 latent。优化目标为：

```text
L = MSE(student_action, teacher_action)
  + latent_loss_weight * MSE(student_latent, teacher_latent)
```

学生阶段不更新教师，不训练 AMP 判别器，也不再计算风格奖励。默认输出目录：

```text
logs/rsl_rl/go2_paper_amp_student/<run>/
├── student_50.pt
├── student_50.onnx
├── ...
├── student_4000.pt
└── student_4000.onnx
```

可用 `--resume student_*.pt` 继续训练。加载时会检查学生记录的教师文件名，避免
把不同教师的网络和标签混用。

## 5. ONNX 与实机状态管理

学生 ONNX 有三个输入和三个输出：

| 名称 | 形状 |
| --- | --- |
| `proprio` | `[B, 45]` |
| `hidden_state` | `[1, B, 256]` |
| `cell_state` | `[1, B, 256]` |
| `actions` | `[B, 12]` |
| `next_hidden_state` | `[1, B, 256]` |
| `next_cell_state` | `[1, B, 256]` |

实机控制器启动、急停恢复、策略重新启用和机器人状态复位时，必须把 hidden/cell
全部清零。正常的每个 20 ms 控制周期，将上一次的两个 `next_*` 原样作为下一次
输入。45 维本体观测顺序、动作尺度、关节顺序、PD 参数和力矩限制与现有 Go2
AMP 完全相同。

部署顺序应为 ONNX 离线测试、独立 sim2sim、吊架低增益测试、低速落地测试，
最后再逐步扩大速度和地形范围。训练完成只说明模型文件可加载，不代表已经满足
实机稳定性要求。

## 6. 2026-11-04 排查记录与本轮工程修改

旧实验停止于7846轮，最后落盘为7800轮。完整速度范围下原始风格奖励约0.029，
专家/策略判别器输出约+0.985/-0.977。分层权重衰减实际已生效，但仍可区分真假。
这些数据支持“风格信号弱”，不能单凭判别器输出证明机器人没有Trot步态。
旧日志中的error_vel_xy/yaw是按最大命令周期归一化后累计的统计，不能直接解释为
固定命令下整段轨迹的平均误差，更不能将单轮illegal_contact日志当成摔倒百分比。

本次改动属于工程实验，并非论文原始超参数的逐项复现：

1. 保留62→1024→512→1 ELU判别器，将每轮判别器批次数从8降至2。
2. 判别器增加0.8损失门限：专家logit已经大于0.8时停止该样本的分类损失；
   策略logit已经小于-0.8时停止该样本的分类损失。梯度惩罚和权重衰减仍更新，
   让过强分类器有机会减弱。目标标签仍为+1/-1。设置margin=0可恢复原始损失。
   门限不裁剪网络输出，也不保证风格奖励永远非零，需继续观察训练曲线。
3. 地形晋级同时检查线速度和偏航跟踪奖励，取两者归一化均值中的较小值。
   持续至少90% episode、无真实终止、两项均达到85%才升级。
   跟踪低于50%或时长不足时降级；零命令和纯转向仍不改变等级。
4. 命令范围前1000轮保持±0.3、±0.2、±0.55；1000到8000轮线性扩大，
   8000轮后达到±1.0、±0.6、±1.0。避免3500/6000轮的分布突然跳变。
5. 此轮重新训练教师，避免旧PPO优化器、旧判别器与新目标同时发生恢复混淆。

参考动作不要求严格覆盖所有指令速度，但当前判别器显式看到机身速度，超出
参考分布会增加真假区分难度。当前数据只有低速独立方向运动；高速复合运动能否
泛化需要验证。若门限后依然表现差，应录制更丰富的实际运动，而不是修改数据中
的速度数值或通过插值伪造高速运动。

## 7. 从零操作教程与原理

以下命令在仓库根目录执行。训练电机、动作缩放与关节顺序使用既有Go2配置。

### 7.1 环境与数据检查

```bash
uv sync
uv run python tools/validate_go2_amp_dataset.py logs/amp/go2_paper_reference \
  --allow-partial --expected-seconds 2.5
PYTEST_DISABLE_PLUGIN_AUTOLOAD=1 uv run pytest -q
```

每个NPZ需要位置、四元数、机身世界/本体速度、关节位置/速度、足端位置、fps及
关节/足端名称。物理控制周期0.02秒，对应50Hz。数据转换必须统一FR、FL、RR、RL
的顺序和四元数约定。检查实际速度曲线，不能把文件名中的目标速度当成实际速度。
四元数符号跳变、差分速度尖峰、步态切换和未稳定的片段应在采集/转换阶段处理。

AMP采样相邻状态(s_t,s_t+1)，学习短时间运动的分布，不逐帧追踪参考时间。
因此策略输入不需要参考帧索引，也不需要把演示动作直接作为网络标签。

### 7.2 教师训练

```bash
uv run go2-train Go2-Velocity-Rough-AMP-Teacher \
  --env.scene.num-envs 1024 --agent.max-iterations 10000 \
  --agent.run-name balanced-paper-amp-fresh \
  --agent.logger tensorboard --agent.upload-model False
```

教师每步读取45维本体感觉，额外读取仿真30维状态和187维扫描。
两个编码器得到8维和16维latent，与本体感觉合并成69维后生成12个关节动作。
编码器通过PPO目标反向传播端到端学习，不需要独立生成latent标签。
Critic的259维观测用于估计回报，部署时不使用Critic。

奖励由任务奖励、稳定性/安全代价和AMP风格奖励相加。风格奖励为
`max(0, 1 - (D-1)^2/4)`；本项目按控制周期缩放，因此原始风格奖励0.2并不意味着
实际每步直接加入0.2。当前AMP权重2、dt=0.02，对应实际贡献0.008。
判别器用真实演示和策略回放学习真假，策略则用判别器评分作为奖励，通过PPO更新。

域随机化包括编码器、质心、足端摩擦、惯性、PD增益与关节摩擦；每4–8秒施加扰动。
5%严格零命令不计算Trot风格奖励，避免为了风格而持续踏步。它们仍获得任务奖励。

### 7.3 日志与停止/恢复

```bash
uv run tensorboard --logdir logs/rsl_rl/go2_paper_amp_teacher
```

重点联合查看风格奖励、两个logit、episode长度、线/角速度任务奖励、地形等级。
奖励上升也可能来自站立或低速跟踪，不能据此宣布步态成功。
地形等级在速度扩大后回落可以是合理适应，持续回落则要固定命令评估。

使用第2节续训命令时，max-iterations表示追加轮数。恢复同一结构的正常实验时
不要重置判别器。恢复会加载优化器及其超参数，CLI中修改优化器参数不一定覆盖
checkpoint中的值；需要修改学习目标时，优先新建明确命名的实验。

后台服务可用systemctl --user status查看；journalctl --user -u 服务名 -f读取日志。
停止服务会发送SIGTERM，最后几十轮可能未保存，恢复时以最近的model_*.pt为准。

### 7.4 教师评估后再蒸馏

```bash
uv run go2-play Go2-Velocity-Rough-AMP-Teacher \
  --checkpoint-file logs/rsl_rl/go2_paper_amp_teacher/YOUR_RUN/model_1000.pt \
  --viewer viser
```

在相同地形和种子下比较多个checkpoint，逐个固定命令：零速、前后0.3、左右0.2、
左右偏航0.4，再测试复合命令和更高速度。每个至少运行20秒，忽略启动过渡，记录
实际本体速度均值、逐步绝对误差、存活时间与对角足接触节律。至少使用3个种子。
平地通过后再测斜坡、楼梯、随机粗糙地形及随机扰动。固定命令评估时关闭命令
随机重采样，并明确是否启用域随机化；不能拿不同难度实验的总奖励直接比较。

教师步态与跟踪合格后，按第3节训练学生。DAgger在学生访问的状态上请求教师动作
和24维latent作为监督；学生不能通过蒸馏获得教师本来不会的能力。
学生loss下降后仍要运行第4节sim2sim：MSE小可能只是大部分关节相似，不保证
足端触地时序或闭环稳定性。LSTM的hidden/cell要持续传递，复位清零。

### 7.5 常见问题定位顺序

- logit迅速到±1、风格奖励很低：先查参考与在线特征坐标、顺序、dt和高度定义，
  再查参考分布与判别器更新强度；降低判别器loss本身不是训练目标。
- 高速或转向差：先固定单轴命令测量，再考虑奖励带宽、课程和数据覆盖。
- 原地踏步：检查5%零命令及其风格屏蔽是否实际生效，检查站立任务奖励。
- 教师好而学生差：检查教师来源、学生控制状态分布、序列边界、done掩码和sim2sim
  hidden/cell传递；不要仅增加学生轮数。
- sim2sim差：先核对关节顺序、角度零位、观测缩放、上一动作、动作尺度、PD和周期，
  再考虑动力学差异。电机限幅不应为了让仿真跑通而任意增大。

## 8. 原论文逐节核对（2026-11-04，以本节纠正前文概括）

来源：Wu等，RA-L 8(8), 4975–4982, 2023，用户提供的正式出版PDF。
下面的页码为期刊页码。第6节门限与全地形连续扩速仅为候选工程实验，尚未启动；
不能称为原论文复现。原文阅读发现的差异优先于前文“与论文一致”的概括。

### 8.1 方法与信息流（4977，Fig.2）

教师输入45维本体、30维特权和187维高度；学生只用45维本体。
特权压缩成8、地形压缩成16，拼接24维latent，再和45维组成69维低层输入。
PPO训练教师时，任务回报的梯度同时训练编码器与低层网络。学生通过监督学习
重建24维latent并模仿12维教师动作。训练低层策略的权重从教师复制后继续更新。
187个点描述采样地面到机器人机身的竖直距离，确实参与教师计算，不直接部署。
论文部署是Go1，固定PD为Kp=20、Kd=0.5；迁移Go2需保留已有真实电机参数约束。

### 8.2 AMP与参考集（4978，II-B/C）

单帧31维=关节角12+关节速度12+本体线速度3+角速度3+相对地形高度1。
相邻两帧拼接62维，不输入时间相位，不监督动作。判别器最小化专家目标+1、
策略目标-1的最小二乘损失与梯度惩罚，文中alpha_gp=10。风格奖励按式(4)计算。
判别器判别正确不是最终目标，最终需要策略的跟踪、自然运动和鲁棒性共同合格。

### 13.6 Rough 摔倒排查后的从头训练（2026-11-05）

本轮清理89个中间检查点和临时测试文件，释放约1022MiB；保留旧运行的最终
`model_5999.pt`、`model_6398.pt`、`model_6797.pt`，以及参考数据、配置和
评估报告。旧根目录辅助脚本和已失效的中间评估也已清理；历史训练文本日志
归入各自运行目录的`console.log`。`logs`根目录只保留`amp/`与`rsl_rl/`。

排查发现：mjlab原始`HfRandomUniformTerrainCfg`明确忽略difficulty，所以旧
random_rough即使处于等级0，也采用2～10cm高度噪声范围。旧模型的训练末期
random_rough平均等级只有约0.164，不能说明已学会该地形。另一个分布差异是
play使用随机地形生成和随机重置，可能直接遇到训练中很少接触的较高难度。

修正位于`src/go2_tasks/terrains.py`，仅用于Go2 rough AMP及其教师：按课程难度
缩放噪声范围。最低难度的高度跨度约1cm，最高难度恢复原来的8cm跨度；实际
生成的最高难度高度场与原生成器在相同随机种子下逐元素一致，回归测试通过。
这会改变后续创建的Go2 rough AMP地形分布，旧模型本身不会自动获得新能力。

新的训练入口保留已验证的baseline任务奖励，设置持续20秒命令及航向目标，
让机器人有机会完成8m地形块的穿越条件，减少4～8秒频繁换向造成的净位移抵消。
继续保留原命令扩速课程：3500轮、6000轮扩速，最终范围不变；训练8000轮，
使完整速度范围有约2000轮适应时间。5%严格零指令、站立参考、论文判别器、
域随机化、随机扰动及Go2电机参数保持不变。此轮不加载任何旧checkpoint。

